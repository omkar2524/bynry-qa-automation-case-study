# Bynry QA Automation Engineering Intern - Case Study

## Overview

This repository contains my solution for the QA Automation Engineering Intern case study provided by Bynry Inc.

The case study focuses on designing a reliable automation approach for a multi-tenant B2B SaaS platform.

## Objectives

The solution covers:

- Debugging and improving flaky Playwright tests
- Designing a scalable QA automation framework
- API testing
- UI automation using Playwright
- API + UI integration testing
- Multi-tenant data isolation
- Cross-browser testing
- Mobile testing using BrowserStack concepts
- CI/CD integration
- Test data management
- Test reporting and debugging strategy

## Technology Stack

- Python
- pytest
- Playwright
- REST API testing
- BrowserStack
- GitHub
- CI/CD concepts
